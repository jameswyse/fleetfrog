Show a repository's working trees on a machine as one outline: each worktree sits under its clone with its branch, changes and T3 Code thread, and opening one shows its actions, upstream, pull request, last commit, folder and changed files in one sectioned card, which closes again with a second click. Merged worktrees gather in a Finished group with a Clean up action that removes them and their branches together, and a Switch branch menu replaces the per-branch buttons. T3 Code threads move to their own tab as cards like T3 Code's sidebar, and repository details move to an About tab.
