See every repository on every machine.

FleetFrog is a self-hosted dashboard for the computers you develop on. An agent on each machine reports its Git repositories to your hub, so you can see what’s uncommitted, unpushed or behind without checking each machine by hand.

How it works

FleetFrog has three parts, and every one of them runs on computers you own.

  1. An agent on each machine

    A single binary for Linux and macOS finds your Git repositories and reports their state. Each machine’s owner decides what the hub may ask it to do.

  2. A hub on your network

    One Docker container collects every report and serves the dashboard. People sign in with a password or through your OpenID Connect provider.

  3. A dashboard in your browser

    Every repository against every machine, with its branch, changes, stashes and commits to push or pull. Fetch, pull and clone from there too.

Get started

The hub runs in Docker, and each machine needs Git. FleetFrog is in early beta, so expect rough edges and breaking changes between 0.x versions.

Read the setup guide on GitHub

  1. 1Run the hub

    Download the Compose file and start the hub, then open the dashboard on port 7420. 

    curl -fsSLO https://raw.githubusercontent.com/jameswyse/fleetfrog/main/compose.yaml
docker compose up -d

  2. 2Add your machines

    Install the agent on each computer you develop on, then pair it from Settings › Fleet in the dashboard. 

    curl -fsSL https://github.com/jameswyse/fleetfrog/releases/latest/download/install.sh | sh

    Or download the agent yourself, and check it against the release’s checksums.

    • Linux ARM64
